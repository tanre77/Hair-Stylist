<h1>Hair Stylist</h1>

<p>اعثر على حلاق أو مصفف شعر قريب، واحجز كرسيًا، وأضف إكرامية، وادفع باستخدام <span dir="ltr">Venmo</span> أو <span dir="ltr">Apple Pay</span>.</p>

<p>الكراسي في هذا الإصدار محلات تجريبية حول <span dir="ltr">Powell</span> و<span dir="ltr">Columbus</span> في ولاية <span dir="ltr">Ohio</span>. استبدل اسم مستخدم <span dir="ltr">Venmo</span> الخاص بالمصفف قبل إرسال المال — الأسماء المعروضة عناصر نائبة.</p>

<h2>ما يمكنك فعله</h2>

<ul>
<li>اسمح بالموقع، أو اختر حيًا، ورتّب الكراسي حسب المسافة</li>
<li>احفظ مصففًا، واختر خدمة، وخذ وقتًا متاحًا</li>
<li>أضف إكرامية (<span dir="ltr">15%</span> أو <span dir="ltr">18%</span> أو <span dir="ltr">20%</span> أو <span dir="ltr">25%</span> أو مبلغًا مخصصًا) عند الدفع</li>
<li>ادفع المجموع في <span dir="ltr">Venmo</span>، فيفتح مع المبلغ والملاحظة مملوءَين</li>
<li>ادفع باستخدام <span dir="ltr">Apple Pay</span> على <span dir="ltr">iPhone</span> عبر ورقة <span dir="ltr">Payment Request</span></li>
<li>أضف إكرامية مرة أخرى لاحقًا من <span dir="ltr">Visits</span></li>
</ul>

<h2>التثبيت</h2>

<p>على <span dir="ltr">iPhone</span>: مشاركة، ثم إضافة إلى الشاشة الرئيسية. على <span dir="ltr">Android</span>: قائمة المتصفح، ثم تثبيت التطبيق.</p>
