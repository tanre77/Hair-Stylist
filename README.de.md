# Hair Stylist

Finden Sie einen Friseur oder Stylisten in der Nähe, buchen Sie einen Stuhl, geben Sie Trinkgeld und zahlen Sie mit Venmo oder Apple Pay.

Die Stühle in dieser Version sind Beispielsalons in der Umgebung von Powell und Columbus, Ohio. Ersetzen Sie den Venmo-Benutzernamen der Stylistin oder des Stylisten, bevor Sie Geld senden — die angegebenen Namen sind Platzhalter.

## Das können Sie tun

- Standort freigeben oder eine Nachbarschaft wählen und Stühle nach Entfernung sortieren
- Eine Stylistin oder einen Stylisten speichern, eine Leistung wählen und einen freien Termin nehmen
- Beim Bezahlen ein Trinkgeld hinzufügen (15 %, 18 %, 20 %, 25 % oder einen eigenen Betrag)
- Die Summe in Venmo zahlen; Venmo öffnet sich mit ausgefülltem Betrag und Hinweis
- Mit Apple Pay auf dem iPhone über das Payment Request-Blatt zahlen
- Später erneut Trinkgeld geben, unter Visits

## Installieren

Auf dem iPhone: Teilen, dann Zum Home-Bildschirm. Auf Android: Browsermenü, dann App installieren.
