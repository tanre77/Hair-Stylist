# Hair Stylist

近くの理容師またはヘアスタイリストを見つけ、席を予約し、チップを添えて、Venmo または Apple Pay で支払います。

この版の席は、オハイオ州 (Ohio) の Powell と Columbus 周辺のサンプル店舗です。送金する前にスタイリストの Venmo ユーザー名を差し替えてください。表示されている名前はプレースホルダーです。

## できること

- 位置情報を許可するか、地区を選び、席を距離順に並べる
- スタイリストを保存し、サービスを選び、空いている時間を取る
- 会計時にチップを追加する（15%、18%、20%、25%、または任意の金額）
- 合計を Venmo で支払う。Venmo は金額とメモが入った状態で開く
- iPhone で Payment Request シート経由の Apple Pay で支払う
- あとから Visits で再びチップを渡す

## インストール

iPhone では：共有、次にホーム画面に追加。Android では：ブラウザのメニュー、次にアプリをインストール。
