# B and S

理容室とサロン。席を予約し、メニューと担当者、または最初の空き時間を選び、内金か来店分の全額を支払います。

見本の店は Powell と Columbus のあたりにあります。デモモードでは、予約台帳も支払いもスタジオも、この端末の中だけに残ります。

## できること

- 料金、所要時間、前後の余白があるメニューを選ぶ
- 担当者を指名する、または空いている席ならどれでも選ぶ
- 二重に入らない、実際の空き時間を取る
- 内金か来店分の全額を、定額または任意のチップを添えて支払う
- カードまたは Venmo で支払う。Apple Pay は表示付きのデモ決済で、本番のカード鍵があるときは出ません
- 来店リンクを開き、日時を変えるか取り消す
- 本番のカード決済を返金できるのは、その来店リンクから、またはサインインしたオーナーからだけで、しかも店の期限内に限られます
- スタジオを開く。日と週のカレンダー、スタッフの勤務時間、メニュー、ふさいだ時間、顧客、そしてキャンセルと無断キャンセルの方針

カード鍵がないときは、デモモードが既定です。`VITE_DEMO_MODE=1` のとき、またはページを `?demo=1` で開いたときもオンになります。訪れた人はデモのゲストとして入ります。サインイン画面はありません。本番のカード決済とオーナーのサインインを使うには、`VITE_DEMO_MODE=0` にして下の鍵を追加します。

カード番号はブラウザで確認されたあと捨てられます。台帳が残すのはトークン、ブランド、下4桁だけです。

本番のカード請求は、公開済みのメニュー、店の内金の方針、最大 $500 のチップから、サーバー側で金額が決まります。ブラウザが送った金額が一致しなければ拒否されます。返金には、署名された支払い記録に加えて来店リンクまたはオーナーのセッションが必要で、支払済みの額を超えることはできません。

## 環境

| 変数 | 場所 | 用途 |
| --- | --- | --- |
| `VITE_DEMO_MODE` | 公開 | `1` はデモモードを強制します。`0` は強制的にオフにします。未設定なら鍵に従います。 |
| `VITE_STRIPE_PUBLISHABLE_KEY` | 公開 | カード欄。これが設定されていると Stripe を使います。 |
| `STRIPE_SECRET_KEY` | サーバー | 請求の作成と返金。ブラウザには出しません。 |
| `VITE_SQUARE_APPLICATION_ID` | 公開 | ウェブ決済アプリケーションの ID。Stripe が未設定のときに使います。 |
| `VITE_SQUARE_LOCATION_ID` | 公開 | そのアプリケーションのロケーション。 |
| `SQUARE_ACCESS_TOKEN` | サーバー | 請求と返金。ブラウザには出しません。 |
| `OWNER_EMAIL` | サーバー | スタジオへのサインイン。デモモードがオフのときだけです。 |
| `OWNER_PASSWORD` | サーバー | スタジオへのサインイン用パスワード。 |
| `OWNER_NAME` | サーバー | サインイン後に表示する名前。 |
| `OWNER_SESSION_SECRET` | サーバー | 任意。オーナーのセッションに署名します。なければオーナーのパスワードに戻ります。 |
| `PAYMENT_TICKET_SECRET` | サーバー | 任意。返金に使う支払い記録に署名します。なければ決済代行の秘密に戻ります。 |

`?demo=1` は、鍵があってもデモモードをオンにします。
