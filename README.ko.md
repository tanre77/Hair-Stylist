# Hair Stylist

근처 바버 또는 헤어 스타일리스트를 찾고, 의자를 예약하고, 팁을 더한 뒤 Venmo 또는 Apple Pay로 결제하세요.

이 버전의 의자는 오하이오주 (Ohio) Powell과 Columbus 주변의 샘플 가게입니다. 돈을 보내기 전에 스타일리스트의 Venmo 사용자 이름을 바꾸세요. 적힌 이름은 자리 표시자입니다.

## 할 수 있는 일

- 위치를 허용하거나 동네를 고르고, 의자를 거리순으로 정렬
- 스타일리스트를 저장하고, 서비스를 고르고, 빈 시간을 잡기
- 결제 시 팁 추가 (15%, 18%, 20%, 25% 또는 직접 입력한 금액)
- 합계를 Venmo로 결제. Venmo가 금액과 메모가 채워진 채로 열림
- iPhone에서 Payment Request 시트를 통해 Apple Pay로 결제
- 나중에 Visits에서 다시 팁 주기

## 설치

iPhone: 공유, 그다음 홈 화면에 추가. Android: 브라우저 메뉴, 그다음 앱 설치.
