# B and S

Барбери й салони. Забронюйте крісло, оберіть послугу й людину або перший вільний час і сплатіть завдаток чи весь візит.

Зразки салонів розташовані навколо Powell і Columbus. У деморежимі книга, платежі й студія лишаються на цьому пристрої.

## Що можна зробити

- Обрати послугу з ціною, тривалістю та буферами
- Обрати людину або будь-яке вільне крісло
- Узяти справжнє вільне вікно, яке не забронюють двічі
- Сплатити завдаток або весь візит, із готовими чи власними чайовими
- Платити карткою або через Venmo. Apple Pay — це позначений демоплатіж, і він вимкнений, коли задано ключі живої картки
- Відкрити посилання візиту, щоб перенести або скасувати
- Повернути живий картковий платіж можна лише з цього посилання або ввійшовши як власник, і лише в межах вікна салону
- Відкрити студію: календар дня й тижня, години персоналу, послуги, заблокований час, клієнти та правила скасування й неявки

Деморежим увімкнено за замовчуванням, якщо немає ключів картки. Він також увімкнений, коли `VITE_DEMO_MODE=1` або сторінку відкрито з `?demo=1`. Відвідувачі заходять як демогість. Екрана входу немає. Поставте `VITE_DEMO_MODE=0` і додайте ключі нижче, щоб користуватися живими картковими платежами та входом власника.

Номери карток перевіряються в браузері й відкидаються. Книга зберігає лише токен, бренд і останні чотири цифри.

Живе списання з картки оцінюється на сервері за опублікованою послугою, правилом завдатку салону та чайовими щонайбільше $500. Сума, яку надіслав браузер і яка не збігається, відхиляється. Для повернення потрібні підписаний запис про платіж і посилання візиту або сесія власника, і повернення не може перевищити сплачене.

## Середовище

| Змінна | Де | Призначення |
| --- | --- | --- |
| `VITE_DEMO_MODE` | Публічно | `1` примусово вмикає деморежим. `0` вимикає його. Без значення йде за ключами. |
| `VITE_STRIPE_PUBLISHABLE_KEY` | Публічно | Поле картки. Stripe використовується, коли цей ключ задано. |
| `STRIPE_SECRET_KEY` | Сервер | Створює та повертає списання. Ніколи не потрапляє в браузер. |
| `VITE_SQUARE_APPLICATION_ID` | Публічно | Ідентифікатор застосунку вебплатежів. Використовується, коли Stripe не задано. |
| `VITE_SQUARE_LOCATION_ID` | Публічно | Точка цього застосунку. |
| `SQUARE_ACCESS_TOKEN` | Сервер | Списує та повертає. Ніколи не потрапляє в браузер. |
| `OWNER_EMAIL` | Сервер | Вхід до студії, лише коли деморежим вимкнено. |
| `OWNER_PASSWORD` | Сервер | Пароль для входу до студії. |
| `OWNER_NAME` | Сервер | Ім'я, яке видно після входу. |
| `OWNER_SESSION_SECRET` | Сервер | Необов'язково. Підписує сесію власника. Якщо немає, береться пароль власника. |
| `PAYMENT_TICKET_SECRET` | Сервер | Необов'язково. Підписує запис про платіж для повернень. Якщо немає, береться секрет платіжної служби. |

`?demo=1` вмикає деморежим навіть за наявності ключів.

## Встановлення

На iPhone: «Поділитися», потім «На Початковий екран». На Android: меню браузера, потім «Встановити застосунок».
