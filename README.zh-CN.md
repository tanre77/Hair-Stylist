# Hair Stylist

查找附近的理发师或发型师，预约一个座位，添加小费，并用 Venmo 或 Apple Pay 付款。

此版本中的座位是俄亥俄州 (Ohio) Powell 与 Columbus 一带的示例店铺。汇款前请更换发型师的 Venmo 用户名——所列姓名均为占位符。

## 你可以做什么

- 允许定位，或选择一个街区，并按距离排列座位
- 收藏一位发型师，选择服务，并选取一个空闲时间
- 结账时添加小费（15%、18%、20%、25% 或自定义金额）
- 在 Venmo 中支付总额；Venmo 会打开并填好金额和备注
- 在 iPhone 上通过 Payment Request 面板使用 Apple Pay 付款
- 之后可在 Visits 中再次给小费

## 安装

在 iPhone 上：点“共享”，然后“添加到主屏幕”。在 Android 上：浏览器菜单，然后“安装应用”。
