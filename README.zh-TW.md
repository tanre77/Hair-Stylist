# Hair Stylist

尋找附近的理髮師或造型師，預約一個座位，加入小費，並用 Venmo 或 Apple Pay 付款。

此版本中的座位是俄亥俄州 (Ohio) Powell 與 Columbus 一帶的示例店家。匯款前請更換造型師的 Venmo 使用者名稱——所列姓名皆為佔位符。

## 你可以做什麼

- 允許定位，或選擇一個街區，並依距離排列座位
- 收藏一位造型師，選擇服務，並選取一個空閒時段
- 結帳時加入小費（15%、18%、20%、25% 或自訂金額）
- 在 Venmo 支付總額；Venmo 會開啟並填入金額與備註
- 在 iPhone 上透過 Payment Request 面板使用 Apple Pay 付款
- 之後可在 Visits 再次給小費

## 安裝

在 iPhone 上：點「分享」，然後「加入主畫面」。在 Android 上：瀏覽器選單，然後「安裝應用程式」。
